## 2. 確定しているが、実装が仕様と異なる可能性・要確認

| 項目 | 現状 |
| --- | --- |
| ドラッグ交代の「不要な二重選択メニュー省略」 | 控え選択メニューは省略されるが、**捨てるエネルギーの選択と最終確認の2段階は残る**（ドロップ先の指定だけで入れ替え先は決まる）。これを「二重メニュー」と見なすかは要判断 |
| 補色の付与（色調整中） | 色調整中は「一時色」の補色だけが付与不可で、**元のベースカラーの補色は付与できる**（カードは0枚分として数えられ、ターン終了後も残る）。仕様の意図が不明（❓、`tests/rules.test.mjs` に現状の特性テスト） |
| 色調整カード・増強カードの色表記 | カード自体に色（色調整＝赤/黄/青、増強＝橙/緑/紫）が割り当てられ手札に表示されるが、効果に使われない（表示のみ） |

- 種族名（ムカデ／ドラゴン／ゴーレム／騎士／骸骨）は仮。**種族による性能差は無い**（テスト済み）。
