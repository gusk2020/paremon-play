## 現在の主要仕様（会話の後発決定が優先）
- 30枚デッキ／初期手札5枚／毎ターン1枚ドロー。前衛1、控え最大2。現行仮デッキ：モンスター12、基本6色エネルギー12、色調整3、増強3。
- 先攻初回攻撃不可、1ターン攻撃1回で終了。勝利条件は2/3/4体撃破を開始前に選択、または相手場の前衛と控えが全滅。山札からターン開始時に引けないと敗北。
- 現行仮HP10。2ワザ：基本攻撃2（自由色1）、強攻撃3（現在のベースカラー1+自由色1）。弱点に対するダメージ2倍。増強+1は倍率の前に加算。通常攻撃でエネルギーは消費しない。
- 相性は紫→青→緑→黄→橙→赤→紫（矢印側が相手に有利）。ゲーム比喩であり物理の厳密な再現ではない。
- エネルギー0枚のモンスターは無色で弱点なし。1枚目の色がベースカラー。追加同色は各2枚分、非補色の異色は各1枚分。補色（赤緑、橙青、黄紫）は追加不可。
- 色調整は前衛のベースカラーをそのターンだけ変更し、カードの色・順序は維持する。変更後の同色カードはすべて各2枚分、補色カードは0枚分（破棄なし）、他色1枚分。ターン終了時に元へ戻り自動再計算。無色には色調整不可。色指定コストにも有効枚数を使用可能。
- 最初のエネルギーを捨てた場合は残存最古のカードの色へ変更。空なら無色。通常の交代はエネルギー1枚破棄・1ターン1回。色調整/増強は各1ターン1回。
- 手札/前衛/控えのタップで中央ウィンドウ。カードドラッグによる配置・付与・増強・色調整・入れ替え。前衛・控えのドラッグ交代ではドロップ先を対象とし、不要な二重選択メニューは省略する方針（実装は確認要）。
- 画像は無色線画と6色差分を表示する方向。現在のモンスター種名は仮で、性能差は未導入。
- 進化・混色の本格ルール、モンスター個別ステータスは保留。
